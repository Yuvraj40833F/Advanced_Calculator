
# 🧮 GDG Calculator

A web-based calculator project built using HTML, CSS, and JavaScript. The project consists of two versions, starting with a basic calculator and progressing to an advanced calculator with additional mathematical functionality.

## 🚀 Project Versions

### V1 – Basic Calculator
- Addition, subtraction, multiplication and division
- Decimal number calculations
- Clear and delete functionality
- Simple and user-friendly interface

### V2 – Advanced Calculator
- Basic arithmetic operations
- Scientific calculations
- Percentage calculations
- Square and square root
- Power operations
- Parentheses support
- Keyboard input support

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Choose either V1 or V2.
4. Open its `index.html` file in your browser.

No additional installation is required.
